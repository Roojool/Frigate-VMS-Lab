# Experiment Results & Data Artifacts

This directory stores structured empirical benchmark results generated by the `frigate-vms-lab` collector.

---

## Output Data Structure

Every experiment execution creates a structured JSON artifact adhering to the following research schema:

```json
{
  "experiment_id": "EXP-001",
  "physical_run_completed": false,
  "timestamp": null,
  "duration_seconds": 600,
  "interval_seconds": 1.0,
  "warmup_seconds": 30,
  "environment": {
    "platform": null,
    "python_version": null,
    "cpu_count_logical": null,
    "memory_total_bytes": null,
    "docker_available": null,
    "frigate_version": null
  },
  "streams": [
    {
      "url": "rtsp://CAMERA_USERNAME:***@CAMERA_1_HOST/STREAM_PATH",
      "codec": null,
      "width": null,
      "height": null,
      "nominal_fps": null
    }
  ],
  "samples": [],
  "summary": {
    "total_samples": 0,
    "system": {
      "cpu_percent": {
        "sample_count": 0,
        "mean": null,
        "median": null,
        "min": null,
        "max": null,
        "stdev": null,
        "p50": null,
        "p95": null
      }
    },
    "docker": {},
    "frigate": {
      "cameras": {}
    }
  }
}
```

---

## Artifact Generation & Analysis

```bash
# Print summary statistics to terminal
frigate-vms-lab analyze results/run.json

# Render formatted Markdown research report
frigate-vms-lab report results/run.json --output results/report.md
```
