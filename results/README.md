# Experiment Results & Data Artifacts

This directory stores structured empirical benchmark results generated by the `frigate-vms-lab` collector.

---

---

## Artifact Generation & Analysis

```bash
# Print summary statistics to terminal
frigate-vms-lab analyze results/run.json

# Render formatted Markdown research report
frigate-vms-lab report results/run.json --output results/report.md
```
